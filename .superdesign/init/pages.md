# Page dependency trees

## `/` — authenticated WebUI

Entry: `embedded_resources/web_interface/index.html`

Dependencies:

- `embedded_resources/web_interface/index.css`
- runtime `/theme.css` generated by `serveWebUIFile()` in `src/core/wifi/webInterface.cpp`
- `embedded_resources/web_interface/index.js`
- JSON/text/binary endpoints registered by `configureWebServer()` in `src/core/wifi/webInterface.cpp`

Main regions: header actions, SD/LittleFS capacity selectors, breadcrumb and file actions, file table, upload/settings/navigator/info/input/credential/editor dialogs, TFT screen canvas and input navigator.

## `/login` — authentication

Entry: `embedded_resources/web_interface/login.html`

Dependencies:

- `embedded_resources/web_interface/index.css`
- runtime `/theme.css` generated by `serveWebUIFile()` in `src/core/wifi/webInterface.cpp`
- `/login` POST handler registered by `configureWebServer()`

## Candidate MaliOS views (not yet implemented)

The requested Dashboard, QR Studio, Wi-Fi and Portal Studio are intended as lightweight views inside the authenticated shell. They must reuse the same CSS/JS delivery pipeline and cannot assume a browser framework or external dependency.
